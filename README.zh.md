> 惠文高中留學指南 (HWSH Study Abroad Guide)

[English Version](README.md)

一個專為惠文高中學生打造的網站，協助同學探索留學選項，內容包含學長姐的經驗分享、生活小提醒，以及人脈資源。

> 簡介

惠文留學指南為學生提供清楚且有系統的留學資訊，包括各國概況、申請步驟與留學生活提醒。
本專案由校友與校方共同協力開發，確保資訊的準確性與實用性，幫助未來申請者做好準備。

> 開發動機

許多惠文學生對於留學申請流程與學校選擇感到不確定。本專案的目的是集中可靠資訊、提升資訊取得的便利性，並降低申請過程中的不安與門檻。

> 技術架構

使用 Next.js 與 React 開發，並部署於 Vercel。
